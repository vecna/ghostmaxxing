# web-files

This folder contains static files copied to the root of https://ghostmaxxing.vecna.eu for deployment.

- `CITATION.cff`: Citation metadata for the Ghostmaxxing project, including preferred citation details.
- `llms.txt`: Large-language-model indexing instructions for discoverability and AI-friendly site summarization.
- `robots.txt`: Search engine crawling rules for the public site.
- `security.txt`: Security contact and disclosure information for responsible vulnerability reporting.
- `sitemap.xml`: XML sitemap listing the site’s public pages for search engines.
- `apple-touch-icon.png`: Apple home-screen icon copied into the deployed root.
- `manifest.webmanifest`: Web app metadata and icon references for the deployed site.
