Open the Lab ↗ How face recognition works

Save a reference and try a change

  1. Allow camera access and keep one face in frame. Start with even light and a steady camera.
  2. Select Save before applying makeup. Open Faces to see the number assigned to each reference.
  3. Make a change and check the number and distance in the top bar. Compare the same pose, distance and lighting when checking the effect of one change.
  4. Use 2D for face-api landmarks and 3D for the MediaPipe mesh. Turn on both to see them together.

Read the top bar

The left number is the closest stored reference. The distance beside it is compared with the Lab threshold of 0.58. A smaller distance means closer to that reference.

  • Red means the reference is within the match threshold.
  • Yellow means the closest reference is just outside the threshold, up to 0.63.
  • Green means the closest reference is farther away.
  • Gray stripes mean that the detector could not see a face.

The last eight seconds move from right to left. Each segment carries the reference number reported at the time. In a group, compare that number with the saved faces to tell whether the model identified the person you expected.

Switch tools or share a clip

References saved from a camera in Realtime or from a clean photo in Ghostyle Transfer appear in Faces when you use the same browser and site. Face references stay local. Use Faces to delete a reference.

Copy image copies the current camera view with the project credit and any available recognition reading. Record 1s creates a clip locally. Upload lets you preview or copy the recording and asks for consent before sending it for moderation.
