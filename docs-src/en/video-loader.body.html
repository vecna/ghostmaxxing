Analyse makeup in a recorded video

Inspect a frame at an exact timestamp or track changes across a sampled segment of a local video.

Measurements use the video playhead time. Model outputs may vary across browsers, hardware and inference backends.

Purpose

Test makeup videos

The Loader lets you pause an MP4 and repeat a test at the same timestamp. For live camera input, use the Lab.

The file stays local to the browser. Selecting a video does not upload it.

Minimum procedure

Inspect a frame or analyse a sequence

  1. Wait for the local models to load, then choose Select local video.
  2. Scrub to the frame you want to inspect and select Analyse this frame.
  3. For a sequence, scrub to a clear reference frame, select Select base at the displayed time, choose a sample interval and select Analyse video.
  4. Read the timeline and results in Evidence and story order. Use Download report or Download technical log to keep a local copy.

Read the model lanes

The report keeps MediaPipe coverage, experimental ImageEmbedder similarity, and face-api distance in separate lanes. A lower face-api Euclidean distance means a closer match. A higher ImageEmbedder cosine similarity means more similar visual input.

Repeatability

Control the frame. Record the environment.

  • Pause before pressing an action. Confirm the playhead after the seek completes.
  • Use the same file and timestamp when comparing revisions of the application.
  • Record browser, model files, hardware backend, and thresholds for consequential comparisons.
  • Use the video position when referring to a result.
  • A frame with no detected face is a valid observation, but it does not produce an identity comparison.
Limits

This is a work in progress.

For Ghostyle extraction from a pair of photos, use Ghostyle Transfer. Proposed Loader features include additional before-and-after diagnostics. Discuss them in the github issues.
