Edit and replay Ghostyles.

Ghostyle Player shows the camera result beside the JavaScript source and includes a native brush.

Open Ghostyle Player ↗

Open the source

On desktop, choose a Ghostyle by name and select Show code. The camera and the scrolling editor each take half of the workspace. Edit the JavaScript and select Reload to apply it locally. Use Auto-indent to align the highlighted JavaScript and Download .js to save the current draft. Drafts stay open while switching between Ghostyles in the current tab.

Draw with the brush

Enable Brush, choose color, size and opacity, then draw over the camera. The strokes follow the face landmarks. Use Undo or Clear to change the drawing. On desktop, Bake to code opens a reusable Ghostyle draft from the strokes.

Inspect and capture the preview

Toggle 2D and 3D independently to check landmark placement. Ghostyle settings such as the UV Stripes colors and opacity appear below the camera and update the preview immediately. Use Copy image to paste the current preview with the project credit and, when available, the Ghostyle name. Record 2s captures the camera and its visible layers. Open Upload to preview or copy the clip and to consent to sending it for moderation.

Start from a photo pair or a fuzzer result

Ghostyle Transfer extracts a module from two photos. The Local Fuzzer generates modules in Docker. To preview a downloaded module, replace the text in the desktop source editor and select Reload.
