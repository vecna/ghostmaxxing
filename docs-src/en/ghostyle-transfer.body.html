Extract a Ghostyle from two photos

Use one clean photo and one painted photo of the same face to create a reusable Ghostyle. Photo processing stays in the browser.

Open Ghostyle Transfer ↗ Edit a Ghostyle in Player

Choose the two photos

Use clear photos of one person with similar pose, framing and lighting. Select the reference image under Clean photo and the image with makeup under Painted photo. The tool aligns both faces to a shared UV map and estimates the painted areas from their differences. Changes in lighting or expression can appear in the extracted pattern.

Adjust and preview

Change Sensitivity and inspect the result in Ghostyle preview. The preview starts on the clean photo. Use Try another face (optional) to see how the pattern maps to another photo.

Download and reuse the source

Select Download Ghostyle .js to save the generated module. To preview it live on a desktop, open a Ghostyle in Ghostyle Player, select Show code, replace the draft with the contents of the downloaded file and select Reload.

Compare with saved faces

When the browser has saved face references, Transfer can show a local comparison for each source photo. Select Save clean face to Lab to add a numbered reference to the local archive shared by tools on the same site in the same browser.
