# docs

This folder contains generated public documentation for the project. Functional pages are generated from the editable `docs-src/` source; the symbol reference is generated JSDoc under `docs/jsdoc/`; and published screenshot assets live under `docs/assets/screenshots/` with capture provenance manifests.

The functional pages under `develop/`, `glossary/`, `guides/`, `maintain/`, and `understand/`, plus the root index and compatibility redirect, are generated by `npm run docs:functional`. JSDoc is generated from source comments and `jsdoc.clean.json` with `npm run docs`; the root README and `JSDOC_index.md` provide the useful human summary.

Use `npm run docs:all` for both documentation families, or `npm run docs:rebuild` for a clean JSDoc rebuild. Do not edit generated HTML as the source of a lasting change. Screenshot captures are produced separately by `npm run docs:screenshots`; their manifest records dimensions, crop, viewport, and state provenance.
