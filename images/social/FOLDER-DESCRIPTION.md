# images/social

This folder contains social-profile media that does not fit the root social-card files.

`header-1500x500.png` is the wide social header/banner image shown in the visual specimen page and intended for social profile surfaces. The 1200x630 `ghostmaxxing-generic.jpg` is the shared JPEG preview used by Open Graph and Twitter metadata. The root-level `images/social-card.svg` and `images/social-card-square.svg` are editable SVG artwork sources.

The PNG file is excluded from code2prompt because it is a visual asset. This description keeps the relationship between profile headers and root social-card metadata clear.
