# images/social

This folder contains social-profile media that does not fit the root social-card files.

`header-1500x500.png` is the wide social header/banner image shown in the visual specimen page and intended for social profile surfaces. The `ghostmaxxing-{glasses,pole,canopy,generic,gallery}` JPEGs are generated by `scripts-dev/build-social-cards.cjs`: unsuffixed files are 1200 × 630, `-square` files are 1200 × 1200, and `-wide` files are 1500 × 500. The unsuffixed `ghostmaxxing-generic.jpg` remains the shared Open Graph and Twitter preview. The root-level `images/social-card.svg` and `images/social-card-square.svg` are legacy artwork sources rather than inputs to this generator.

The PNG file is excluded from code2prompt because it is a visual asset. This description keeps the relationship between profile headers and root social-card metadata clear.

The `ghostmaxxing-{glasses,pole,canopy,generic,gallery}` JPEG/PNG files are generated social-preview cards. Edit `scripts-dev/social-cards.html`, then run `node scripts-dev/build-social-cards.cjs`. Landscape outputs are 1200 × 630, `-square` outputs are 1200 × 1200, and `-wide` outputs are 1500 × 500; the capture manifest records selected exports.
