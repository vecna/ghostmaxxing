# images/social

This folder contains social-profile media that does not fit the root social-card files.

`header-1500x500.png` is the wide social header/banner image shown in the visual specimen page and intended for social profile surfaces. Root-level `images/social-card.svg` and `images/social-card-square.svg` remain the Open Graph and preview card assets used by page metadata.

The PNG file is excluded from code2prompt because it is a visual asset. This description keeps the relationship between profile headers and root social-card metadata clear.
