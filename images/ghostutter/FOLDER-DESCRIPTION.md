# images/ghostutter

This folder contains the Ghostutter shard artwork used by the spinner/dazzler visual system.

`shard.svg` is the current mark used by `styles/ghostutter.css` and the Ghostutter specimen/demo pages. `legacy-spiral.svg` preserves the older spiral artwork for reference and migration notes.

The SVG files are excluded from code2prompt because they are visual assets. This description documents that Ghostutter motion and behavior live in `styles/ghostutter.css` and `scripts/ghostutter.js`, while this folder only supplies the shard image source.
