# images/icons

This folder contains SVG surveillance-camera icons used by the genealogy, specimen, homepage, and editorial motif demos.

The icon set includes bullet, dome, cube, pill/depth-array, smart-glasses, and street-pole camera forms. Many icons have two states: a dazzled/static lens variant and an `-alive` open-lens variant. The surrounding pages and `styles/ghostutter.css` combine these icons with Ghostutter marks for hover, focus, and historical camera-family displays.

The SVG files are excluded from code2prompt because they are visual assets. This description preserves the purpose and naming convention of the omitted icon set.
