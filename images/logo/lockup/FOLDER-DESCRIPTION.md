# images/logo/lockup

This folder contains the smaller current lockup subset used by specimen and brand pages.

`horizontal-onlight.svg` is the compact horizontal Ghostmaxxing lockup for light/orange surfaces. `stacked-ondark.svg` is the stacked lockup for dark/green surfaces. Broader legacy or alternate lockup exports remain in `images/logo/`.

The SVG files are excluded from code2prompt because they are visual brand assets. This folder description records when these compact lockups should be preferred.
